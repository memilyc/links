# Emily Chang · links

A small, static link page for GitHub Pages, styled to match the terminal/pixel language of the portfolio.

## Deploy

This site needs no build step. In GitHub, enable Pages from the repository's `main` branch and `/ (root)` folder.

## Personalise

The three destinations live directly in `index.html`:

- LinkedIn: `https://www.linkedin.com/in/memilyc`
- Instagram: `https://www.instagram.com/emgineer_my`
- Portfolio: `https://memilyc.github.io/portfolio`

The theme toggle remembers the visitor's choice in `localStorage` and respects the OS theme on first visit.
